CYBER-ATTACK DETECTION FRAMEWORK - COPY TO LOCAL LAPTOP
===========================================================

STEP 1: CREATE PROJECT FOLDER ON YOUR LAPTOP
--------------------------------------------
1. Open terminal/command prompt on your laptop
2. Create project directory:
   mkdir cyber-attack-detection-framework
   cd cyber-attack-detection-framework

STEP 2: CREATE DIRECTORY STRUCTURE
----------------------------------
Run these commands in your project folder:

mkdir -p src/algorithms
mkdir -p src/power_system
mkdir -p src/attacks
mkdir -p src/protection
mkdir -p src/utils
mkdir -p data/raw
mkdir -p data/processed
mkdir -p data/ieee_systems
mkdir -p results/phase1
mkdir -p results/phase2
mkdir -p results/phase3
mkdir -p tests
mkdir -p notebooks

-----------------------------
Copy each file content exactly as shown in the workspace.
