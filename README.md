# Detection and Mitigation of Cyber-Attacks on Distance Protection Systems

## PhD Research Simulation Framework

This repository contains a comprehensive simulation framework for detecting and mitigating cyber-attacks on distance protection systems and circuit breaker control using machine learning techniques.

## Research Phases

### Phase 1: Algorithm Development and Initial Testing
- Machine Learning Algorithm Implementation
- Statistical Methods Development
- Power System Analysis Integration

### Phase 2: Framework Integration and Comprehensive Testing
- Multi-tier Architecture Implementation
- Attack Scenario Testing
- Performance Optimization

### Phase 3: Validation, Documentation, and Dissemination
- Large-Scale Validation
- IEEE Test System Implementation
- Comprehensive Analysis

## Installation

```bash
pip install -r requirements.txt
```

## Project Structure

```
├── src/                          # Main source code
│   ├── algorithms/               # ML algorithms implementation
│   ├── power_system/            # Power system analysis
│   ├── attacks/                 # Attack simulation modules
│   ├── protection/              # Protection system models
│   └── utils/                   # Utility functions
├── data/                        # Dataset storage
├── results/                     # Simulation results
├── tests/                       # Unit tests
└── notebooks/                   # Jupyter notebooks for analysis
```

## Usage

Run the main simulation:
```bash
python src/main.py
```
